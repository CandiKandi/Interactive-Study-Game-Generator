How to Host on GitHub Pages

  1. Create a GitHub Repository: Go to github.com/new and name it study-game-generator. Set visibility to Public.
  2. Upload this single file: Rename this HTML file to index.html and upload or commit it directly to the root of your repository.
  3. Enable GitHub Pages: Go to Settings → Pages in your repository. Under Build and deployment, set Source to Deploy from a branch, select main (or master) branch and folder / (root), then click Save.
  4. Share your app! Your interactive AI game studio will be live at https://yourusername.github.io/study-game-generator/!
